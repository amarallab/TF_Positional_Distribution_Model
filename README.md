## A principled approach to the identification of biologically relevant transcription factor binding sites
This repository contains scripts to reproduce figures for the manuscript "A principled approach to the identification of biologically relevant transcription factor binding sites". Scripts are either associated with raw data processing or divided based on individual figures in the manuscript. \\
Prior to running the scripts, please download the associated publically available data sets as specified in the respective markdown file. Create a sub-directory "Figures" for each figure to be saved.
